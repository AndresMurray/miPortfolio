Centra – Gestión de Cursos para Kinesiología

Abril 2026 – Actualidad (Freelance)
centracursos.com

Sistema web integral para un centro de kinesiología que permite la gestión completa de cursos y alumnos, incluyendo un panel de administración robusto y una landing page editable orientada a clientes.

  • Módulo de cursos con alta, edición, habilitación/inhabilitación y gestión de clases por curso.

OdonLoop – Sistema de Gestión Odontológica

Proyecto Profesional
odonloop.com

Sistema web para la gestión integral de turnos y pacientes odontológicos. Implementa un portal diferenciado por roles (paciente / odontólogo), un odontograma interactivo basado en notación FDI, seguimiento clínico con imágenes y exportación de historial clínico a formato PDF.

  • Portal web con control de acceso y flujos diferenciados para pacientes y odontólogos.
  • Odontograma interactivo digital interactivo basado en la notación internacional FDI.
  • Notificaciones automatizadas de turnos y confirmaciones de citas por correo electrónico.
  • Gestión y carga multimedia de estudios e imágenes clínicas almacenados de forma segura.
